# X 互关助手

**X 互关助手**是一个本地运行的 Chrome 扩展：扫描你的关注与粉丝，整理出“互关”“没回关我”“我还没回关”三类名单，再配合白名单、保护规则、试运行和每日上限，帮助你核对关注关系、清理关注列表和回关粉丝。

先看清名单，再决定怎么处理。

**当前版本：v0.2.8** · [下载最新版](https://github.com/adminisweb/x-follow-helper/releases/latest) · [反馈问题](https://github.com/adminisweb/x-follow-helper/issues) · 作者 X：[@ASMD_BLSH](https://x.com/ASMD_BLSH)

## 下载与安装

1. 打开 [Releases 下载页](https://github.com/adminisweb/x-follow-helper/releases/latest)，在 Assets 中下载 **`x-follow-helper-0.2.8.zip`**。
2. 解压 ZIP。打开解压后的文件夹，确认里面直接能看到 `manifest.json`。
3. Chrome 地址栏输入 `chrome://extensions`，打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择含有 `manifest.json` 的文件夹。
5. 打开 [x.com](https://x.com) 并登录，点击扩展图标进入仪表盘。

这是通过 GitHub 分发的扩展，需要手动加载；不要把 ZIP 文件直接拖进浏览器。要求 Chrome 110 或更新版本。

## 能做什么

- 扫描关注和粉丝，区分“没有回关我”“互相关注”“我还没回关”。
- 手动选择名单，执行回关或取关；扫描后默认不勾选任何人。
- 白名单支持手动添加、导入和导出；可设置新关注宽限期、认证账号和粉丝数保护规则。
- 被保护规则排除的账号可以展开查看原因；白名单账号不能直接覆盖取关。
- 提供试运行、随机间隔、批次休息、每日上限、失败暂停与操作记录。
- 可选自动回关模式；取关始终由用户手动发起。
- 白名单、设置和扫描记录保存在本地，多个仪表盘页面同步白名单。

## 第一次使用

1. 在“设置”中打开“试运行”，先检查扫描结果和白名单。
2. 点击“检查接口”，确认日志中能够找到 Followers / Following 查询。
3. 如果找不到查询 ID，先在 x.com 打开自己的“粉丝”和“关注”列表各一次，再回来重试。
4. 核对名单后，再决定是否关闭试运行并执行操作。

运行期间需要保持仪表盘和一个已登录的 x.com 标签页打开，电脑不要进入睡眠。同一浏览器只允许一个仪表盘执行任务，其他仪表盘显示为只读。

## 更新已有扩展

下载新版并解压后，在 `chrome://extensions` 中重新加载扩展，再刷新 x.com 标签页并重新扫描。不要用旧扫描结果继续执行任务。

如需保留已有数据，建议先备份原扩展文件夹，用新版文件覆盖原目录后点击“重新加载”；避免先删除扩展再安装，因为删除扩展可能一并清除本地数据。

## 数据与权限

扩展声明的权限为 `storage`、`unlimitedStorage`，以及 `x.com` / `twitter.com` 的站点访问权限。白名单、设置、扫描结果与操作记录保存在浏览器本地；扫描和关注操作会向 X 发送请求，扩展也会读取 X 的网页脚本以适配接口。

## 使用前请看

- 本项目与 X 官方无关联，也不保证 X 接口长期可用；X 改版后可能需要更新扩展。
- 自动或批量关注、取关存在触发平台规则、限流或账号限制的风险。内置间隔和上限不能保证账号安全。
- 先试运行并核对名单。白名单内账号不会被取关；不要对未核实的扫描结果直接执行操作。
- 遇到登录失效、403、429 或账号限制时，停止任务，先确认账号状态和日志。
